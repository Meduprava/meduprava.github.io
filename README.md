## Перед публикацией

1. Откройте `assets/config.js`.
2. После создания счётчика Яндекс Метрики вставьте его номер в `YANDEX_METRIKA_ID`.
3. В `robots.txt` и `sitemap.xml` замените `YOUR-USERNAME` на ваш логин GitHub.
4. Загрузите содержимое этой папки в корень репозитория GitHub Pages.

`FORM_ENDPOINT` оставлен пустым: текущий сайт не имеет серверного обработчика формы.
